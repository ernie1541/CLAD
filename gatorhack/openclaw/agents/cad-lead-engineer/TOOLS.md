# Tools

- `cadflow` skill — create Traveler jobs, read status, relay and answer approval gates, run the CAD sandbox.
- `sessions_spawn` — summon `cad-sub-engineer` agents (one per sub-assembly) in direct-chat mode.
- `exec` — only for the `curl` commands the `cadflow` skill documents. Do not run anything else.

Traveler API base: `http://127.0.0.1:8765` (override with `$TRAVELER_URL`).
